# 桌游规则遗忘点卡片库

一个纯前端本地应用，用来管理桌游收藏中的规则遗忘点、常见争议、开局准备和计分提醒。支持按最近未玩、人数范围和复杂度筛选，并在详情里展示聚会前快速复习卡片。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。无外部依赖、无后端，进度保存在浏览器 localStorage。

## 规则抽问台

页面顶部的「规则抽问台」用于聚会前抽问，预置三款收藏（奥尔良、盖亚计划、花砖物语）。

玩法：

1. 选择「今晚人数」，只抽人数适配游戏里**未掌握**的规则；不适配的游戏在题目条中置灰。
2. **答错回队尾**，本趟稍后补考；答对记一次累计，**累计两次答对才掌握并退场**。
3. **同一趟每道待掌握题先各出现一次**（随机洗牌），答错回队尾的题本趟补考；一趟走完还有未掌握题时，自动洗牌开下一趟。
4. 切换人数时：当前题仍适配则不动；当前题不再适配则**直接换题且不计成绩**，页面会给出提示。
5. 某款适配游戏的题**全部掌握后锁定这局成绩**（题数、对错数、起止时间）；之后增删改规则**留给下一局**（标记「规则有改动」），点「开下一局」清零进度再来。
6. 人数、趟次队列和每款游戏的进度都会自动存档，刷新页面可继续。

### 文件拆分

| 文件 | 职责 |
| --- | --- |
| `app.js` | 收藏库宿主（增删改、筛选、详情），保持原样 |
| `quiz-store.js` | 进度存档：localStorage 持久化、规则稳定身份同步、单局锁定与开新局 |
| `quiz-engine.js` | 抽题判断：人数适配、未掌握题入队、趟次洗牌、答错回队尾、两次答对退场、换人数换题 |
| `quiz-ui.js` | 页面接入：渲染抽问台、绑定人数/对错/开新局事件、监听收藏库变化 |
