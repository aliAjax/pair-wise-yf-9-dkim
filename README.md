# 桌游规则遗忘点卡片库

一个纯前端本地应用，用来管理桌游收藏中的规则遗忘点、常见争议、开局准备和计分提醒。支持按最近未玩、人数范围和复杂度筛选，并在详情里展示聚会前快速复习卡片。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 规则抽问台

页面顶部切换到「抽问台」即可开局自测：

- 选择当晚人数后，只从适配人数的游戏里抽未掌握的规则。
- 题目以翻卡形式出现：先回忆，翻面核对后自评「答对 / 答错」。
- 答错直接回队尾；同一道题累计答对两次才算掌握并退场，答错不清零累计答对次数。
- 队列带「趟」机制：同一趟里每道待掌握题先各出现一次，全部走完后再重新洗牌进入下一趟。
- 开局中途切换人数：当前题若不再适配，立即换下一道适配题，这次换题不计任何成绩；之前答对的进度保留。
- 某个切到的人数没有适配游戏时显示空场提示，再切回来可继续，不会锁定。
- 当前适配游戏的题目全部掌握后自动锁定本局成绩（用时、趟数、正确率、各游戏掌握数）。锁定后改动或新增规则只影响下一局——开局时会对收藏重新拍快照。
- 本局进度与历史成绩都保存在 localStorage，刷新不丢失；最近 20 条锁定成绩可回看。

业务代码按职责拆为三个文件，均为原生 JS、无新增依赖、无后端：

| 文件 | 职责 |
| --- | --- |
| `quiz-engine.js` | 抽题判断：适配过滤、趟队列、掌握/锁定判定、切人数换题 |
| `quiz-store.js` | 进度存档：本局会话持久化、锁定成绩历史 |
| `quiz-ui.js` | 页面接入：视图切换、翻卡渲染、事件绑定 |
